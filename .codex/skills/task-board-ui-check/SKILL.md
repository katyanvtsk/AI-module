Прочитай AGENTS.md.

Получи контекст:

- Выполни `git status --short`.
- Прочитай `git diff` и `git diff --staged`.
- Найди затронутые компоненты и стили.

Из сообщения пользователя определи:

- Сценарий проверки.
- Размер экрана; по умолчанию 390×844 и 1440×900.
- URL приложения; если не указан, выясни адрес сервера разработки.

Открой приложение в браузере и проверь выбранный сценарий
на указанных размерах экрана.

Для длинных названий проверь перенос текста, размеры карточек,
доступность кнопок и переполнение колонок.
Для тестовых изменений используй изолированное хранилище браузера.

Подготовь отчёт: что проверено, какие проблемы воспроизведены,
шаги воспроизведения и скриншоты.
Если браузер недоступен, явно сообщи, что визуальная проверка
не выполнена.

Не меняй исходный код.
Без общих рекомендаций и неподтверждённых выводов.
