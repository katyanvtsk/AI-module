- Поведение при загрузке и её ошибке. В TaskBoard начальное значение задач — [], отдельного признака загрузки нет. Простое условие покажет сообщение также до получения данных и после ошибки загрузки. Для минимального изменения предлагаю сохранить существующий цикл загрузки; если сообщение должно означать именно успешно загруженную пустую колонку, понадобится дополнительное состояние в TaskBoard и тесты загрузки.
- Оформление не задано. Предлагаю обычный текст под заголовком, с умеренным отступом и читаемым контрастом, без дополнительных кнопок.
